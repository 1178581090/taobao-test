# 推广活动分析 — 产品设计文档

## 一、背景与目标

### 问题
平台推广和营销活动太多（直通车、引力魔方、万相台、淘客、聚划算、天天特卖、运费险、淘金币……），卖家难以判断：
- 该从哪个先开始？
- 每个渠道要花多少钱、怎么操作？
- 同行在用哪些，我缺了什么？

### 目标
一个**推广启动指南**，核心产出是优先级排序的行动清单——直接告诉用户「下一步做什么、为什么、怎么做、花多少钱」。

### 分期

| 阶段 | 内容 | 状态 |
|------|------|------|
| 一期 | 推广启动指南：同行对标 + 内置渠道知识 + 行动清单 | 本次开发 |
| 二期 | ROI 数据分析：录入花费/成交额，计算投入产出比，预算优化建议 | 后期 |

一期聚焦**打开销量**，不依赖用户录入精确数据。

---

## 二、数据来源

| 数据类型 | 来源 | 获取方式 |
|----------|------|----------|
| 同行服务工具标签（运费险/淘金币/7天无理由等） | 淘宝搜索结果页 | 浏览器扩展自动抓取 |
| 同行活动标签（聚划算/天天特卖等） | 淘宝搜索结果页 | 浏览器扩展自动抓取 |
| 用户已开通的工具/活动 | — | 手动勾选 |
| 用户月推广预算 | — | 手动填写（可选） |

## 三、数据模型

### 3.1 我的工具状态（用户勾选，localStorage: `tb_promo_mystatus`）

```json
{
  "freightInsurance": false,
  "goldCoins": false,
  "sevenDayReturn": false,
  "fastRefund": false,
  "globalDistribution": false,
  "zhitongche": false,

  "wanxiangtai": false,
  "taoke": false,
  "monthlyBudget": 0

```

二期扩展时在此结构上增加 `spend` 和 `revenue` 字段。

### 3.2 同行对标数据

复用竞品分析 Tab 的 `analyzeAndRender()` 产物：
- 同行服务工具覆盖率（运费险 X%、淘金币 Y%……）
- 同行活动标签频率分布
- 同行天猫/淘宝店铺占比

### 3.3 渠道知识库（内置，硬编码）

每个渠道预置：名称、类型、简要说明、预估成本、门槛、操作路径、搜索加权影响。

```json
{
  "id": "freightInsurance",
  "name": "运费险",
  "type": "tool",
  "desc": "退货补运费，买家更敢下单",
  "cost": "按售价 1%~2%，单均 ¥0.5~2",
  "threshold": "无门槛，千牛一键开通",
  "path": "千牛卖家中心 → 商家保障 → 运费险 → 立即加入",
  "weight": "搜索加权 + 转化率提升"
}
```

## 四、分析逻辑

### 4.0 推荐可信度原则

同行搜索结果数据量小（演出服定制属于小众类目，搜索结果可能仅 20-30 个商品，显示活动标签的更少），因此推荐依据采用**分层置信度**模型：

| 层级 | 依据来源 | 可信度 | 说明 |
|------|----------|--------|------|
| 硬知识 | 渠道机制本身 | ★★★ 可靠 | 运费险提升转化率是淘宝全平台通用规律，不依赖同行数据 |
| 同行参考 | 搜索结果中的同行标签 | ★★☆ 辅助 | 有同行数据时作为增强信号，无数据时不影响推荐 |
| 类目经验 | 演出服定制品类特征 | ★★★ 可靠 | 定制类退货率高、客单价高、复购率低，这些特征是确定的 |

**核心原则：推荐不能建立在不可靠的数据上。同行数据只做加分，不做决策依据。**

### 4.1 行动清单生成规则

每条推荐渠道按以下逻辑评分：

**第一层：渠道机制硬知识**（决定性）

每条渠道内置以下属性：
- `baseScore` — 基础推荐分（0-100），根据渠道在"打开销量"这件事上的有效性预先定义
- `costLevel` — low / medium / high
- `complexityLevel` — 一键开通 / 需要配置 / 需要持续运营
- `effectDesc` — 该渠道为什么有效（基于平台机制，非同行数据）

**第二层：同行数据**（加分项，不影响基础排序）

- 同行搜索有该渠道标签 → 同行的覆盖率数字作为"为什么"文案中的佐证
- 同行数据不足 → 降级显示"根据行业经验推荐"，不展示可能不准确的数字

**第三层：用户现状**（过滤条件）

- 用户已开通 → 从推荐列表中移除
- 用户未开通 → 保留在推荐列表中

### 4.2 优先级排序

```
P0（立刻做）：低成本 + 一键开通 + 搜索加权/转化率直接影响
P1（尽快做）：中等成本 + 配置后可自动运行
P2（可尝试）：需要持续运营 或 成本较高 或 适合预算充足后尝试
```

排序主要依据渠道本身的 baseScore 和 costLevel，同行数据仅影响"为什么"文案的措辞。

### 4.3 为什么文案的两种模式

| 同行数据情况 | 文案模板 |
|-------------|----------|
| 同行数据充足（≥10 个商品有该标签） | 「同行 XX% 已开通（X/Y 个商品）」+ 渠道机制说明 |
| 同行数据不足 | 仅显示渠道机制说明，如「运费险能降低买家下单顾虑，演出服定制类退货率偏高，有运费险转化率通常提升 10-20%」 |

### 4.4 每条行动项的结构

| 要素 | 数据来源 |
|------|----------|
| 做什么 | 渠道名称 |
| 为什么 | 同行覆盖率（有数据时）+ 渠道效果说明（硬知识兜底） |
| 怎么做 | 内置操作路径 |
| 花多少钱 | 内置成本估算 |
| 预期效果 | 内置效果描述 |

## 五、页面布局（推广分析 Tab）

### 5.1 整体结构

左右两栏布局（同竞品分析页）：

**左侧面板**：
- 搜索状态提示（是否已有竞品搜索数据）
- 我的推广现状（勾选已开通的工具/活动 + 月预算输入）
- "生成推荐"按钮

**右侧面板**：
1. 综合状态卡片（已开通 X 项 / 推荐开通 Y 项 / P0 优先 Z 项）
2. 行动清单（按优先级分组：P0/P1/P2，每组下列出具体行动项）
3. 同行对标卡片（服务工具/活动覆盖率表，含"你已开"/"你未开"标记）
4. 渠道详情（折叠面板，所有渠道的知识库信息）

### 5.2 「我的现状」录入 UI

- 渠道列表，每个前面 checkbox
- 分两组：**服务工具**（运费险、淘金币、7天无理由、极速退款）+ **付费推广**（直通车、引力魔方、万相台、淘客）
- 月推广预算输入框（选填，用于二期 ROI 分析）
- 全部 checkbox，勾选即保存到 localStorage

### 5.3 样式规范

沿用现有 CSS 变量和组件规范，与竞品分析 Tab 保持一致。

## 六、与现有功能的关系

| 现有功能 | 关系 |
|----------|------|
| 竞品分析 Tab | 推广分析复用其搜索结果中的同行活动标签。用户需先在竞品分析 Tab 完成一次搜索（有数据），再切到推广分析 Tab |
| 明日清单 Tab | 推广分析的行动清单可一键写入明日清单 |
| 浏览器扩展 | 不需要改动，活动标签抓取已就绪 |

## 七、技术实现

### 7.1 渠道知识库

定义在 JS 常量 `CHANNEL_KNOWLEDGE`，数组，每条包含 `id/name/type/desc/cost/threshold/path/weight`。

### 7.2 数据流

```
竞品分析 Tab 搜索 → analyzeAndRender() 完成后
  → 将 sortedActivities 和 activityCount 挂到 window._lastAnalysis
  → 推广分析 Tab 读取 window._lastAnalysis
  → 同用户勾选的 myStatus 比对
  → 生成行动清单
```

### 7.3 localStorage 键名

| 键名 | 内容 |
|------|------|
| `tb_promo_mystatus` | 我的工具/活动开通状态对象 |
| `tb_promo_monthly_budget` | 月推广预算（二期使用） |

二期在 `tb_promo_mystatus` 基础上扩展：

```json
{
  "zhitongche": {
    "enabled": true,
    "spend30d": 1500,
    "revenue30d": 4500
```

## 九、不做

- 不自动连接千牛 API（无公开 API）
- 不修改浏览器扩展
- 不做直通车关键词级分析
- 不做其他平台（拼多多、抖音）推广（后期再说）
- 二期 ROI 分析本次不开发

## 十、验收标准

| 验收项 | 要求 |
|--------|------|
| 现状勾选 | 勾选/取消后立即保存到 localStorage，刷新保持 |
| 同行数据复用 | 竞品分析搜索后，推广 Tab 能读取同行活动标签并显示覆盖率 |
| 行动清单 | 优先推荐未开通 + 同行覆盖高的渠道，每个包含"做什么/为什么/怎么做/花多少钱/预期效果"五要素 |
| 渠道知识库 | 至少覆盖运费险、淘金币、7天无理由、极速退款、直通车、引力魔方、万相台、淘客 |
| 空状态处理 | 未搜索时提示"请先在竞品分析 Tab 完成搜索"；搜索后但同行数据少时标记"类目样本少" |
| 写入明日清单 | 支持将行动项一键写入明日清单 |
| 样式一致性 | 与现有页面风格统一 |
| 无控制台报错 | 所有交互路径无 JS 异常 |
