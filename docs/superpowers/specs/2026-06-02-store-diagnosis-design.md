# 店铺诊断 Tab + 标题工作台 — 设计规格

**日期**: 2026-06-02  
**状态**: 已确认（design-review 修订）  
**关联**: 竞品分析 Tab / 推广分析 Tab / 活动筛选 Tab

---

## 1. 目标

解决「僵尸店铺」问题：新店没销量 → 没排名 → 没曝光 → 更没销量的死循环。

现有三个 Tab 覆盖了「有曝光后怎么转化」（活动报名、推广渠道、竞品对标），但缺少「曝光怎么来」的进攻能力。

新增第四个 Tab **「店铺诊断」**，包含两个子模块：

| 模块 | 定位 | 核心问题 |
|------|------|----------|
| 店铺激活向导 | 防守 | 店铺基础权重有没有短板？ |
| 标题工作台 | 进攻 | 买家能不能搜到我的商品？ |

---

## 2. 架构

### 2.1 文件结构

不新增文件，所有代码内联到 `index.html`，遵循现有架构模式：

- **HTML** — 新增 Tab 导航按钮 + 两个模块的 DOM 结构
- **CSS** — 新增样式内联在 `<style>` 中
- **JS** — 新增渲染函数、事件处理、数据持久化逻辑

### 2.2 Tab 导航

## 3. 模块一：店铺激活向导

### 3.1 清单项目（8 项）

#### 基础装修（4 项）

| # | 项目 | 说明 | 操作指引 |
|---|------|------|----------|
| 1 | 店招上传 | 1200×120 横幅，放店名+主营类目 | 给 2 个同行店招参考图 + 千牛装修直达链接 |
| 2 | 店铺简介 | 100 字以内，告诉买家你是谁/做什么 | 提供文案模板（填空式：我是___，专注___，___年经验） |
| 3 | 类目属性补全 | 品牌/适用性别/适用场景等属性填满 | 千牛商品编辑页直达链接 |
| 4 | 店铺认证 | 保证金缴纳 / 主体认证状态 | 千牛卖家中心直达 |

#### 权重激活（2 项）

| # | 项目 | 说明 | 操作指引 |
|---|------|------|----------|
| 5 | 破零销量 | 完成第 1 单，打破零销量状态 | 建议：找朋友下单 / 低价引流款 / 送样给熟人 |
| 6 | 首场活动报名 | 从可参加活动中选门槛最低的报名 | 联动活动筛选 Tab 的「可参加」结果，给直达链接 |

#### 内容基础（2 项）

| # | 项目 | 说明 | 操作指引 |
|---|------|------|----------|
| 7 | 微淘/订阅基础帖 | 发 2-3 条内容（没粉丝也要发，权重因子） | 提供内容模板（上新预告 / 买家秀 / 面料展示） |
| 8 | 商品短视频 | 30 秒以内主图视频或详情页视频 | 提供拍摄提纲（前 3 秒展示全身 → 细节 → 场景） |

### 3.2 交互行为

- **未完成项**：复选框 + 标题 + 2-3 句说明 + `去操作` 链接
- **已完成项**：变灰缩起，只显示标题 + 绿色 ✓，下次刷新不展开
- **顶部进度条**：`████████░░░░ 3/8 已完成`，全部完成显示「店铺基础搭建完成」
- **全部完成后**：显示鼓励文案 + 引导进入标题工作台
- **复选框防抖**：点击后 200ms 内忽略重复点击，防止 localStorage 竞态写入

### 3.3 去操作链接

`去操作` 按钮点击后通过浏览器扩展 `openWithSteps` 打开千牛对应页面，注入步骤跟随面板（复用现有能力）。

### 3.4 数据存储

- **键名**：`tb_store_checklist`
- **格式**：`{ "1": true, "2": false, ... }` — 项目序号 → 完成状态
- **生命周期**：持久化，手动清除浏览器数据才消失
- **损坏恢复**：读取时 try-catch + JSON.parse 失败 → 返回全 false 默认值，不阻塞渲染
- **写入失败**：localStorage 配额超限时静默降级（本次勾选不持久化），下次打开时恢复上次成功保存的状态

### 3.5 首次使用

- 首次打开（无 `tb_store_checklist` 数据）→ 全部 8 项展开且未勾选，进度条显示 0/8
- 提示文案：「完成以下 8 项基础搭建，让店铺活起来」

## 4. 模块二：标题工作台

### 4.1 商品选择器

**问题**：用户可能有多个商品需要写标题（多条不同款式的裙子），历史记录需按商品区分。

**方案**：输入区顶部增加一个简单的商品名输入框：

- 输入商品名称（如「红色肚皮舞套装」）作为当前编辑的商品标识
- 下拉列表显示之前输入过的商品名（从 `tb_title_history` 中提取去重）
- 切换商品时，下方属性输入区恢复该商品上次的偏好设置
- 生成的历史记录关联到当前商品名，按商品分组展示
- 不填也能用，历史记录归入「未命名商品」

### 4.2 输入区

**核心属性（必填/选填标识）：**

| 属性 | 类型 | 选项 | 默认值（首次使用） |
|------|------|------|------|
| 商品名 | 文本 | 自填 + 历史下拉 | 空 |
| 舞种 | 下拉+自填 | 肚皮舞 / 民族舞 / 爵士 / 现代 / 古典 / 拉丁 / 街舞 / 芭蕾 / 其他（自填） | 空（必填，未选时「抓取」按钮禁用） |
| 性别 | 单选 | 女 / 男 / 通用 | 女 |
| 面料 | 多选+自填 | 蕾丝 / 雪纺 / 氨纶 / 亮片 / 流苏 / 棉麻 / 网纱 / 其他 | 无选中 |
| 场景 | 多选 | 年会 / 舞台 / 考级 / 婚礼 / 广场舞 / 日常 / 其他 | 无选中 |
| 价格档位 | 自动填入 | 读取 `tb_my_cost`，显示为价格区间（成本 × 1.5~2.5） | 若成本为 0/NaN/负数/未填，显示「未设置成本」 |

**输入约束**：
- 舞种自填文本：最长 20 字符，`<` `>` `&` 等 HTML 特殊字符做转义处理
- 面料自填文本：最长 20 字符，同上转义
- 商品名：最长 30 字符，同上转义
- 所有用户输入内容渲染时使用 `textContent`（非 `innerHTML`），防止 XSS

### 4.3 关键词分析区

#### 数据来源

点击「抓取竞品关键词」→ 通过浏览器扩展搜索淘宝（关键词 = `舞种 + 演出服`）→ 提取搜索结果前 2 页商品标题 + **搜索结果总数** → 解析 N-gram 词频。

复用现有能力：
- 扩展的 `search` 模式抓取搜索页商品卡片
- `getKeywordFrequency()` 做 N-gram 分词统计
- `tb_af_scan` 中的千牛数据辅助判断搜索热度

**新增扩展能力**：搜索页 `content.js` 需额外提取搜索结果总数（淘宝搜索结果页顶部显示「共 N 件」），用于判断关键词竞争度。

#### 关键词分级

| 级别 | 标签颜色 | 判断规则 | 示例 |
|------|----------|----------|------|
| 强推词 | 绿色 | 竞品高频 + 搜索结果总数 < 5000（低竞争） | `肚皮舞演出服 年会` |
| 防守词 | 黄色 | 竞品高频 + 搜索结果总数 > 5000（高竞争） | `民族风 新款` |
| 长尾补充 | 灰色 | 低频但精准匹配你的选品 | `亮片流苏 大码` |

> 竞争度阈值（5000）为初始经验值。若扩展无法提取搜索结果总数（淘宝改版等），降级为纯词频排序，所有词标为灰色，并在结果区顶部提示「竞争度数据暂不可用」。

#### 加载态

点击「抓取竞品关键词」后的状态流转：

1. **按钮禁用态** → 按钮文字变为「搜索中...」，灰色不可点击，旁边显示当前步骤（如「正在搜索同类商品...」）
2. **进度更新** → 复用现有 `handleAutoProgress` 模式，显示「搜索完成 → 提取关键词 → 分析分级」
3. **完成态** → 按钮恢复为「重新抓取」，结果区渲染关键词标签
4. **超时** → 40 秒超时，提示「搜索超时，请重试或切换到手动输入模式」
5. **扩展未连接** → 降级为手动输入模式（见 4.5 边界情况表）

**Tab 切换行为**：抓取进行中用户切换到其他 Tab → 后台继续抓取，回传结果时若当前不在店铺诊断 Tab → 暂存结果，用户切回时渲染。

#### 交互

- 关键词以标签形式展示，可点选/取消
- 选中词高亮，自动进入标题候选区的词库
- 下方显示「已选 N 个词」
- **首次使用**：无缓存数据，关键词区显示引导文案「选择舞种后点击"抓取竞品关键词"开始分析」

### 4.4 标题生成区

#### 生成逻辑

1. 从选中关键词中按优先级排列：强推词 → 长尾补充 → 防守词
2. 拼接模板：
   - **候选 1（搜索导向）**：`[核心词] [场景词] [面料词] [长尾词]` — 关键词堆叠，密度优先，可读性次之
   - **候选 2（点击导向）**：`[营销前缀] [核心词] [场景词]` — 前置「新款」「现货」「定制」等吸引点击的前缀，关键词密度低
   - **候选 3（均衡导向）**：`[核心词] [场景+面料组合] [营销后缀]` — 前半搜索词后半修饰词，兼顾
3. 硬约束：淘宝标题 **30 字**上限（含空格/标点），超出自动裁剪（从末尾逐词移除，优先去掉防守词）
4. 裁剪后仍超 30 字 → 截断并在末尾加 `…`（全角省略号，占 1 字），控制台 warn

> 淘宝标题按 Unicode 码点计数，JS `"".length` 与之吻合。CJK 字符各算 1 字，空格/标点各算 1 字。

#### 交互

- 每个候选标题下方显示字数：`24/30`
- 标题文本可直接点击编辑微调（使用 `contentEditable` 或 `input`，渲染时走 `textContent`）
- 每个候选右侧有「复制」按钮，一键复制到剪贴板
- 复制后短暂显示「已复制」反馈（1.5 秒后消失）
- 复制失败（旧浏览器不支持 Clipboard API）→ fallback：`select()` 选中文本，提示「请手动 Ctrl+C 复制」

### 4.5 历史记录区（折叠）

- 默认折叠，点击「历史记录（N）」展开
- 每条记录：商品名 + 生成时间 + 标题文本 + 当时选中的关键词标签列表
- 按商品名分组，每组内按时间倒序
- 最多保留 20 条（每个商品最多 10 条），超出自动删除最旧的
- 「对比视图」：勾选 2 条同商品的历史记录，左右并排显示差异
- **时间戳**：使用本地时间（`new Date().toLocaleString()`），格式 `2026-06-02 14:30:00`

### 4.6 边界情况

| 场景 | 处理方式 |
|------|----------|
| 未输入舞种就点抓取 | 按钮保持禁用态 + 提示「请先选择舞种」 |
| 竞品搜索返回 0 结果 | 提示「未找到相关竞品，尝试换一个舞种或关键词」 |
| 候选标题超过 30 字 | 从末尾逐词移除，优先去防守词，仍超则截断加 `…` |
| 一个关键词都没选就点生成 | 提示「请至少选择一个关键词」 |
| 复制失败（旧浏览器） | fallback：选中文本让用户手动 Ctrl+C |
| **扩展未安装/未连接** | 降级为手动输入模式：显示文本框让用户粘贴从淘宝手动搜索看到的竞品标题（多行，一行一个标题），本地跑 `getKeywordFrequency()` 做词频分析，竞争度数据不可用时所有词标灰色 |
| **扩展中途断开** | 40 秒超时兜底，超时后提示「搜索超时，请检查扩展是否正常运行」 |
| **扩展返回异常数据** | 字段缺失/格式错误 → try-catch 包裹解析，失败提示「数据格式异常，请重试」 |
| **localStorage 损坏** | 读取各键时 try-catch + JSON.parse 失败返回默认值（空数组/空对象），不阻塞页面 |
| **localStorage 配额超限** | 写入失败静默降级，不弹窗打断用户。优先保留最新记录，删除最旧记录腾空间 |
| **价格未设置或异常** | 成本为 0/NaN/负数/undefined → 输入区价格档位显示「未设置成本」，不参与标题生成 |
| **自定义输入超长** | 舞种/面料/商品名自填截断到 20/20/30 字符 |
| **Tab 切换时抓取进行中** | 后台继续抓取，回传时若不在店铺诊断 Tab → 暂存结果在变量，切回后渲染 |
| **多商品快速切换** | 切换商品时若正在抓取 → 旧抓取结果丢弃，展示新商品的缓存数据或空白状态 |

### 4.7 数据存储

| 键名 | 内容 | 格式 |
|------|------|------|
| `tb_title_prefs` | 按商品名分组的输入偏好 | `{ "红色肚皮舞套装": { "dance": "肚皮舞", "gender": "女", "fabric": ["蕾丝"], "scene": ["年会"] }, ... }` |
| `tb_title_history` | 标题生成历史（含商品名） | `[{ "product": "红色肚皮舞套装", "time": "2026-06-02 14:30:00", "title": "...", "keywords": [...] }, ...]` |
| `tb_title_keywords` | 最近一次抓取的关键词缓存 + 抓取时间 | `{ "fetchedAt": "2026-06-02 14:25:00", "keyword": "肚皮舞演出服", "strong": [...], "defend": [...], "longtail": [...] }` |

**缓存过期**：`tb_title_keywords` 带时间戳，渲染时若距抓取时间超过 **7 天**，在关键词区顶部显示黄色提示「关键词数据已过期，建议重新抓取」。不自动清除旧数据（用户仍可使用旧关键词）。

## 5. 扩展集成

### 5.1 标题工作台关键词抓取

复用现有 `postMessage` → `background.js` 消息通道：

1. `index.html` 发 `{ action: "searchCompetitors", keyword: "肚皮舞演出服" }`
2. `background.js` 创建搜索页后台标签页 → `content.js` search 模式提取商品标题
3. `content.js` **新增提取搜索结果总数**（淘宝搜索页 `.search-count` 或同类选择器，显示「共 N 件」）
4. 回传 `{ titles: [...], totalCount: 12345 }` → `index.html` 跑 `getKeywordFrequency()` 做词频分析
5. 结合 `totalCount` 与阈值比较判断竞争度，给关键词打分级标签
6. `totalCount` 缺失时（淘宝改版导致选择器失效）→ 竞争度分级降级，所有词标灰色

### 5.2 激活向导的去操作链接

复用 `openWithSteps(url, name, ruleId)` 模式，步骤面板内容改为对应清单项的简化指引。

## 6. 非功能约束

- **不新增外部依赖**：所有逻辑纯 JS 客户端计算
- **文件编码**：UTF-8
- **浏览器兼容**：Chrome（Manifest V3 扩展环境）
- **emoji 正则限制**：JS 不支持 emoji 范围字符类正则，避免使用
- **localStorage 键名**：遵循现有 `tb_` 前缀约定
- **安全性**：
  - 所有用户输入渲染使用 `textContent` 或经过 HTML 实体转义，禁止 `innerHTML` 直接插入用户内容
  - 「去操作」链接通过扩展打开前校验 URL 协议（仅允许 `https://`）
- **无障碍性**（基础要求）：
  - 复选框使用 `<input type="checkbox">` 原生控件，自带键盘可访问性
  - 按钮使用 `<button>` 元素，支持 Tab 键导航和 Enter/Space 触发
  - 关键交互元素（按钮/输入框/复选框）有可见的 `:focus` 样式（保留浏览器默认焦点环）
  - 非核心，不要求完整的 aria-label/WAI-ARIA 覆盖
