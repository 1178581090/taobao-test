# 店铺诊断 Tab + 标题工作台 — 设计规格

**日期**: 2026-06-02  
**状态**: 已确认  
**关联**: 竞品分析 Tab / 推广分析 Tab / 活动筛选 Tab

---

## 1. 目标

解决「僵尸店铺」问题：新店没销量 → 没排名 → 没曝光 → 更没销量的死循环。

现有三个 Tab 覆盖了「有曝光后怎么转化」（活动报名、推广渠道、竞品对标），但缺少「曝光怎么来」的进攻能力。

新增第四个 Tab **「店铺诊断」**，包含两个子模块：

| 模块 | 定位 | 核心问题 |
|------|------|----------|
| 店铺激活向导 | 防守 | 店铺基础权重有没有短板？ |
| 标题工作台 | 进攻 | 买家能不能搜到我的商品？ |

---

## 3. 模块一：店铺激活向导

### 3.1 清单项目（8 项）

#### 基础装修（4 项）

| # | 项目 | 说明 | 操作指引 |
|---|------|------|----------|
| 1 | 店招上传 | 1200×120 横幅，放店名+主营类目 | 给 2 个同行店招参考图 + 千牛装修直达链接 |
| 2 | 店铺简介 | 100 字以内，告诉买家你是谁/做什么 | 提供文案模板（填空式：我是___，专注___，___年经验） |
| 3 | 类目属性补全 | 品牌/适用性别/适用场景等属性填满 | 千牛商品编辑页直达链接 |
| 4 | 店铺认证 | 保证金缴纳 / 主体认证状态 | 千牛卖家中心直达 |

#### 权重激活（2 项）

| # | 项目 | 说明 | 操作指引 |
|---|------|------|----------|
| 5 | 破零销量 | 完成第 1 单，打破零销量状态 | 建议：找朋友下单 / 低价引流款 / 送样给熟人 |
| 6 | 首场活动报名 | 从可参加活动中选门槛最低的报名 | 联动活动筛选 Tab 的「可参加」结果，给直达链接 |

#### 内容基础（2 项）

| # | 项目 | 说明 | 操作指引 |
|---|------|------|----------|
| 7 | 微淘/订阅基础帖 | 发 2-3 条内容（没粉丝也要发，权重因子） | 提供内容模板（上新预告 / 买家秀 / 面料展示） |
| 8 | 商品短视频 | 30 秒以内主图视频或详情页视频 | 提供拍摄提纲（前 3 秒展示全身 → 细节 → 场景） |

### 3.2 交互行为

- **未完成项**：复选框 + 标题 + 2-3 句说明 + `去操作` 链接
- **已完成项**：变灰缩起，只显示标题 + 绿色 ✓，下次刷新不展开
- **顶部进度条**：`████████░░░░ 3/8 已完成`，全部完成显示「店铺基础搭建完成」
- **全部完成后**：显示鼓励文案 + 引导进入标题工作台

### 3.3 去操作链接

`去操作` 按钮点击后通过浏览器扩展 `openWithSteps` 打开千牛对应页面，注入步骤跟随面板（复用现有能力）。

### 3.4 数据存储

- **键名**：`tb_store_checklist`
- **格式**：`{ "1": true, "2": false, ... }` — 项目序号 → 完成状态
- **生命周期**：持久化，手动清除浏览器数据才消失

## 4. 模块二：标题工作台

### 4.1 输入区

**核心属性（必填/选填标识）：**

| 属性 | 类型 | 选项 |
|------|------|------|
| 舞种 | 下拉+自填 | 肚皮舞 / 民族舞 / 爵士 / 现代 / 古典 / 拉丁 / 街舞 / 芭蕾 / 其他（自填） |
| 性别 | 单选 | 女 / 男 / 通用 |
| 面料 | 多选+自填 | 蕾丝 / 雪纺 / 氨纶 / 亮片 / 流苏 / 棉麻 / 网纱 / 其他 |
| 场景 | 多选 | 年会 / 舞台 / 考级 / 婚礼 / 广场舞 / 日常 / 其他 |
| 价格档位 | 自动填入 | 读取 `tb_my_cost`，显示为价格区间（成本 × 1.5~2.5） |

### 4.2 关键词分析区

#### 数据来源

点击「抓取竞品关键词」→ 通过浏览器扩展搜索淘宝（关键词 = `舞种 + 演出服`）→ 提取搜索结果前 2 页商品标题 → 解析 N-gram 词频。

复用现有能力：
- 扩展的 `search` 模式抓取搜索页商品卡片
- `getKeywordFrequency()` 做 N-gram 分词统计
- `tb_af_scan` 中的千牛数据辅助判断搜索热度

#### 关键词分级

| 级别 | 标签颜色 | 判断规则 | 示例 |
|------|----------|----------|------|
| 强推词 | 绿色 | 竞品高频使用 + 搜索结果数 < 5000（低竞争） | `肚皮舞演出服 年会` |
| 防守词 | 黄色 | 竞品高频使用 + 搜索结果数 > 5000（高竞争） | `民族风 新款` |
| 长尾补充 | 灰色 | 低频但精准匹配你的选品 | `亮片流苏 大码` |

> 竞争度阈值（5000）为初始经验值，后续可根据实际数据调整。

#### 交互

- 关键词以标签形式展示，可点选/取消
- 选中词高亮，自动进入标题候选区的词库
- 下方显示「已选 N 个词，预计可组合成 M 个标题」

### 4.3 标题生成区

#### 生成逻辑

1. 从选中关键词中按优先级排列：强推词 → 长尾补充 → 防守词
2. 拼接规则：核心词（舞种+演出服）+ 场景词 + 面料/特征词 + 营销词
3. 硬约束：淘宝标题 **30 字**上限（含空格/标点），超出自动裁剪（优先去掉排名最后的防守词）
4. 生成 3 个候选标题，策略略有不同：
   - 候选 1：搜索导向（关键词密度高，适合搜索流量）
   - 候选 2：点击导向（加入吸引点击的修饰词，适合推荐流量）
   - 候选 3：均衡导向（兼顾搜索和可读性）

#### 交互

- 每个候选标题下方显示字数：`24/30`
- 标题文本可直接点击编辑微调
- 每个候选右侧有「复制」按钮，一键复制到剪贴板
- 复制后短暂显示「已复制」反馈（1.5 秒后消失）

### 4.4 历史记录区（折叠）

- 默认折叠，点击「历史记录（N）」展开
- 每条记录：生成时间 + 标题文本 + 当时选中的关键词标签列表
- 最多保留 10 条，超出自动删除最旧的
- 「对比视图」：勾选 2 条历史记录，左右并排显示差异

### 4.5 边界情况

| 场景 | 处理方式 |
|------|----------|
| 未输入舞种就点抓取 | 提示「请先选择舞种」 |
| 竞品搜索返回 0 结果 | 提示「未找到相关竞品，尝试换一个舞种或关键词」 |
| 候选标题超过 30 字 | 自动裁剪，裁剪规则注释在生成逻辑中 |
| 一个关键词都没选就点生成 | 提示「请至少选择一个关键词」 |
| 复制失败（旧浏览器） | fallback：选中文本让用户手动 Ctrl+C |
| 扩展未安装/未连接 | 降级：手动输入关键词模式（备用） |

### 4.6 数据存储

| 键名 | 内容 | 格式 |
|------|------|------|
| `tb_title_prefs` | 上次输入的首选项（舞种/性别/面料/场景） | `{ "dance": "肚皮舞", "gender": "女", ... }` |
| `tb_title_history` | 标题生成历史 | `[{ "time": "2026-06-02 14:30", "title": "...", "keywords": [...] }, ...]` |
| `tb_title_keywords` | 最近一次抓取的关键词结果缓存 | `{ "strong": [...], "defend": [...], "longtail": [...] }` |

## 5. 扩展集成

### 5.1 标题工作台关键词抓取

复用现有 `postMessage` → `background.js` 消息通道：

1. `index.html` 发 `{ action: "searchCompetitors", keyword: "肚皮舞演出服" }`
2. `background.js` 创建搜索页后台标签页 → `content.js` search 模式提取商品标题
3. 回传标题数组 → `index.html` 跑 `getKeywordFrequency()` 做词频分析
4. 结合搜索结果总数判断竞争度，给关键词打分级标签

### 5.2 激活向导的去操作链接

复用 `openWithSteps(url, name, ruleId)` 模式，步骤面板内容改为对应清单项的简化指引。

## 6. 非功能约束

- **不新增外部依赖**：所有逻辑纯 JS 客户端计算
- **文件编码**：UTF-8
- **浏览器兼容**：Chrome（Manifest V3 扩展环境）
- **emoji 正则限制**：JS 不支持 emoji 范围字符类正则，避免使用
- **localStorage 键名**：遵循现有 `tb_` 前缀约定
