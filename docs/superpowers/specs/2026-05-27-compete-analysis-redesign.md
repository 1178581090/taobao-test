# 竞品分析板块重构

## 目标

将竞品分析从「数据展示」升级为「诊断 → 建议 → 行动」闭环，让用户在收集竞品信息后得到可执行的、按优先级排序的操作指引。

## 核心原则

- 建议基于统计数据推断，不做「竞品做了所以你也做」的简单跟随
- 所有结论在竞品分析 Tab 内闭环，不跳转其他 Tab
- 充分利用页面空间，摒弃单调卡片布局

## 新布局结构

```
┌─────────────────────────────────────────────┐
│  📊 诊断总览                                  │
│  竞争力评分 + 三维度进度条 + 首要行动            │
├─────────────────────────────────────────────┤
│  📋 改进清单（按优先级排列）                     │
│  ① 定价建议 — 数据依据 — 操作按钮               │
│  ② 标题优化 — 缺失关键词 — 建议标题             │
│  ③ 活动配置 — 同行覆盖率 — 操作路径             │
├─────────────────────────────────────────────┤
│  🔍 相近竞品对标                               │
│  找出价格 ±15% 的 2-3 个竞品，并排对比：         │
│  · 标题逐词差异 · 活动差异 · 销量差距            │
├─────────────────────────────────────────────┤
│  ▼ 详细数据（默认折叠）                         │
│  原四张分析卡片 + 原始数据表                     │
└─────────────────────────────────────────────┘
```

## 各板块设计

### 1. 诊断总览

三栏布局：

- **竞争力评分**：环形图表展示 0-100 综合分，下方一句话位置描述
- **维度进度条**：价格定位、标题关键词覆盖、活动覆盖三维度，每项显示具体百分比或状态
- **首要行动**：一句话指出最优先该做的事，附带 2-3 个关键数字

综合分计算：价格位置分 + 标题覆盖分 + 活动覆盖分，加权平均后映射到 0-100。

### 2. 改进清单

按优先级排列的行动项，每条包含：

- 优先级编号（1/2/3）
- 影响等级徽标（高/中/低）
- 问题描述 + 数据依据（同行均价、中位价、覆盖率等具体数字）
- 具体操作建议（调价目标区间、缺失关键词列表、活动开通路径）
- 操作按钮（复制建议 / 查看详情）

优先级排序规则：
1. 价格偏离 > 30% → 高优先级
2. 标题高频词缺失 ≥ 3 个 → 中优先级
3. 同行热门活动缺失 → 低优先级

### 3. 相近竞品对标

从竞品中筛选价格在用户商品 ±15% 范围内的 2-3 个商品，并排对比：

- 标题差异词高亮
- 活动配置对比
- 销量差距
- 店铺类型（天猫/淘宝）

如果匹配的相近竞品不足 2 个，扩大范围到 ±25% 或显示提示。

### 4. 详细数据

默认折叠，点击展开。包含原有四张分析卡片（标题关键词、价格竞争力、活动对比、利润测算）和原始数据表。

## 视觉设计

- 亮色主题，与现有 App 一致（背景 #f5f5f5，卡片白色，橙色 #ff5000 强调色）
- CSS 动画：区块依次淡入
- 折叠面板用 CSS transition
- 散点图等图表用纯 CSS/内联 style 属性实现，不依赖第三方库
- 环形评分图用 SVG stroke-dasharray

## 数据来源

无需新增用户输入。竞品数据来自浏览器扩展抓取的搜索结果，用户只需输入售价和成本。用户自己的标题从商品页扩展抓取（已有流程），自己的活动覆盖暂用默认假设（后续可优化）。

## 影响范围

- `index.html`：竞品分析 Tab 的 HTML 结构和 CSS 样式重写，JS 新增/修改以下函数：
  - `analyzeAndRender` — 调整渲染流程，新增板块调用
  - `renderDiagnostic` — 新函数，渲染诊断总览
  - `renderImprovements` — 新函数，渲染改进清单（替代部分 `renderActionPlan` 逻辑）
  - `renderPeerComparison` — 新函数，渲染相近竞品对标
  - `generateChecklistTasks` — 保留，逻辑可能微调
  - 四张分析卡片渲染函数 — 保留，移入折叠区域

## 后续迭代

- 评论分析：扩展插件抓取竞品评论，分析买家关注点和竞品短板
- 活动覆盖自动检测：从用户店铺页抓取已开通活动，避免手动输入
