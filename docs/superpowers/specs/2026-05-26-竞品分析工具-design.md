# 淘宝竞品分析工具 — 产品设计文档

## 一、项目概述

个人专用淘宝店铺诊断工具，聚焦演出服/定制类目。通过浏览器扩展从淘宝搜索结果页实时提取公开数据，在 index.html 中做竞品分析和利润测算，给出可执行的操作建议。

目标用户：自己（演出服/古装/舞蹈服/定制类目卖家），不需要多用户和登录。

已有能力（index.html）：标题诊断（8 维度评分）、标题生成、优化技巧展示。

本次新增：浏览器扩展（数据抓取）、竞品分析（含标题评分 + 价格对比 + 活动分析 + 利润测算）、明日清单。

## 二、模块设计

### 2.1 数据抓取（浏览器扩展）

**方案**：Chrome/Edge 浏览器扩展，轻量级，用户输入关键词后自动打开淘宝搜索结果页提取数据。

**用户操作**：在 index.html 竞品分析 Tab 输入关键词 → 点「搜索分析」→ 扩展自动打开新标签页加载搜索结果 → 页面渲染后注入 Content Script 从 DOM 提取数据 → 结构化 JSON → 数据回到工具。用户只做「输入 + 点击」一步操作。

**提取字段**：

| 字段 | 来源 | 用途 |
|------|------|------|
| 标题 | 商品卡片文本 | 标题诊断 / 关键词对比 |
| 价格 | 价格 DOM | 价格分布 / 利润测算 |
| 月销量 | 付款人数文本 | 销量标杆对比 |
| 店铺名 | 店铺链接文本 | 区分天猫/C店 |
| 活动标签 | 角标 / 标签 DOM | 识别满减/优惠活动 |
| 优惠信息 | 价格下方文案 | 优惠力度 / 利润测算 |

**技术方案**：

- Manifest V3 浏览器扩展
- Content Script 注入淘宝搜索页，从渲染后的 DOM 提取商品列表
- index.html 和扩展之间通过消息传递：index.html → 扩展（发搜索指令）→ 扩展打开标签页 → Content Script 提取数据 → 写回结果
- 扩展分发：初期打包成 `.zip` 私下分发，后续视需求上架 Chrome Web Store

**不去做的**：
- CORS 代理抓取（淘宝搜索页 JS 动态渲染，纯 HTML 请求拿不到数据）
- 淘宝开放平台 API（营销类 API 需 ISV 资质，个人卖家无法调用）
- 自动后台静默抓取（用户需确认数据正确性）

### 2.2 竞品分析（替换原单品诊断）

**定位**：合并原单品诊断和竞品分析为一个 Tab，输入关键词即可同时做对比和诊断。原单品诊断能力并入此模块。

**输入**：搜索关键词 + 我的售价（必填），我的成本（选填，用于利润测算）。

**结果页 4 张卡片**：

**卡片 1：标题质量**
- 复用现有 8 维度标题评分逻辑，对「你的标题」逐项打分的入口
- 同行 Top 10 高频词统计，列出你标题中缺失的关键词
- 输出：缺失词列表 + 建议加入哪些词

**卡片 2：价格竞争力**
- 同行价格区间和均价，你的价格位置
- 偏离 < 10%：正常，无需调整
- 偏离 10%-30%：提示注意，建议差异化或增加入门款
- 偏离 > 30%：警告，给出调整方向

**卡片 3：活动与优惠对比**
- 同行参与的活动和优惠统计（满减、优惠券、淘金币、运费险、新品折扣等）
- 标注哪些活动最多人在用、哪些你可以跟进
- 操作指引指向千牛卖家中心对应入口（告诉你去千牛搜什么，不代替千牛操作）
- 活动数据从搜索结果页实时提取，每次分析都是最新的

**卡片 4：利润测算**
- 输入成本后，自动计算三种场景的利润：不参与活动 / 参加满减 / 满减+优惠券
- 每项显示到手价和利润率
- 成本价存储在 localStorage，下次分析时自动填入

**底部**：
- 原始数据表格（可折叠），展示搜索到的全部商品明细
- 进度指示：「✅ 已分析 X 个商品（搜索页第 1 页）」

**不去做的**：
- 单品诊断独立 Tab（能力已合并到竞品分析）
- 自动调用千牛 API（个人账号无权限）
- 竞品店铺的详细经营数据（淘宝不公开）

### 2.3 明日清单

基于竞品分析结果自动生成可勾选的任务列表，localStorage 持久化。

**任务生成规则**：

| 触发条件 | 生成任务 |
|----------|----------|
| 标题缺失 ≥ 2 个同行高频词 | 「修改标题，加入「xxx」「xxx」关键词」 |
| 价格偏离同行均价 > 30% | 「考虑调整定价，同行均价 ¥xxx」 |
| 同行 X% 使用某活动，你未使用 | 「设置「xxx」活动（去千牛搜索"xxx"）」 |
| 同行 X% 使用某优惠，你未使用 | 「设置「xxx」优惠」 |
| 同行 X% 开通运费险，你未开通 | 「开通运费险」 |
| 同行 X% 支持7天无理由，你不支持 | 「开通7天无理由退货」 |

每项任务显示触发它的数据来源（如「同行 7/10 使用」），让建议有据可查。

底部显示完成进度：`✅ 已完成 X / Y 项`。

## 三、用户操作流程

```
打开 index.html
  ├─ 标题诊断 Tab：粘贴标题 → 即时出分 → 查看逐项建议
  ├─ 标题生成 Tab：填写属性 → 拼接标题 → 复制使用
  ├─ 竞品分析 Tab：输入关键词 + 价格 → 点「搜索分析」
  │     → 扩展打开淘宝搜索结果 → 自动提取数据
  │     → 回到工具 → 查看 4 张结论卡片 + 利润测算
  ├─ 明日清单 Tab：查看自动生成的任务 → 勾选完成 → 进度跟踪
  └─ 优化技巧 Tab：静态知识
```

## 四、技术实现

| 项 | 选择 | 说明 |
|----|------|------|
| 前端 | 纯 HTML/CSS/JS | 无构建依赖，浏览器直接打开 |
| 扩展 | Manifest V3 | Chrome/Edge 兼容 |
| 数据提取 | Content Script + DOM 解析 | 从渲染后的淘宝搜索页提取 |
| 数据传递 | 剪贴板 | 扩展提取后写 JSON 到剪贴板，回到 index.html 自动读取粘贴 |
| 存储 | localStorage | 持久化成本价、清单勾选状态 |

## 五、页面布局

- 主色调：淘宝橙 `#ff5000`
- 背景：`#f5f5f5`，PC 端最大宽度 `900px` 居中
- Tab 切换模式，无页面跳转
- 移动端自适应，无横向滚动
- 组件规范与现有 index.html 保持一致
