# 淘宝店铺运营辅助工具 - 产品设计文档

## 一、项目概述

### 1.1 项目定位

个人专用的淘宝店铺运营辅助工具，集成竞品分析和推广推荐能力。聚焦**演出服/定制类目**，通过浏览器扩展从淘宝公开搜索结果中提取真实数据，给出可执行的操作建议。

### 1.2 核心功能

- **竞品分析** — 输入自己的商品链接 → 自动提取标题/关键词 → 搜索同类竞品 → 四维度分析（标题关键词、价格竞争力、活动优惠、利润测算）
- **推广分析** — 推广渠道操作手册，13 个渠道含效果/步骤/费用/门槛/精力。新手优先推荐卡（3 个免费渠道直达）
- **活动筛选** — 基于千牛店铺数据 + 27 条活动规则的资格匹配推荐引擎（可参加/差一步/暂不可参加/平台暂停）+ 预算计算器
- **店铺诊断** — 店铺激活向导（8 项清单 + 进度条）+ 标题工作台（竞品关键词抓取 → 三级分级 → 3 策略标题生成）

### 1.3 架构

单个 `index.html` 内联所有 CSS/JS，四个 Tab 面板（竞品分析 / 推广分析 / 活动筛选 / 店铺诊断）。配合 Manifest V3 浏览器扩展（`extension/` 目录）实现淘宝数据抓取。

## 二、功能模块

### 2.1 竞品分析

**输入**：自己的淘宝/天猫商品链接 → 点击「分析竞品」

**流程**：
1. 扩展在后台标签页打开商品详情页 → 提取标题、关键词（词典+N-gram）、店铺、售价、销量、商品ID
2. 用提取的关键词拼装淘宝搜索页 URL → 后台标签页打开
3. 抓取搜索结果第一页商品卡片 → 用商品ID精确匹配自己的商品 → 移出竞品列表
4. 回传数据到主页面 → 应用筛选条件 → 渲染分析结果

**分析维度**：

| 维度 | 内容 |
|------|------|
| 诊断总览 | 7 维度改进建议（标题、价格、活动、销量、运费险等），按优先级排序 |
| 标题关键词 | 竞品标题的高频 N-gram 统计，与自己的标题对比 |
| 价格竞争力 | 价格分布（最低/最高/平均/中位），自己的价格位置 |
| 活动优惠 | 竞品使用最多的活动标签排序，覆盖率统计 |
| 利润测算 | 毛利率计算（售价-成本）/售价，运费险估算 |
| 改进清单 | 可操作的改进建议列表 |
| 对标 | 相近价格区间竞品对标表格 |

**筛选条件**：
- 价格区间（最低/最高）
- 标题必须包含的关键词
- 标题必须排除的关键词（预设 14 个演出服类目干扰词：饰品、头饰、配件等）
- 「应用筛选」按钮可在已有数据上重新过滤，无需重新抓取

### 2.2 推广分析

**输入**：基于竞品分析结果 + 用户勾选的已开通渠道

**渠道分类**：

| 类别 | 渠道 |
|------|------|
| 服务工具 | 运费险、淘金币、7天无理由、极速退款、新品成长、iFashion |
| 付费推广 | 直通车、引力魔方、万相台、淘客、极速推、超级直播、超级短视频 |
| 平台活动 | 聚划算、天天特卖、淘宝秒杀 |

**每个渠道包含的信息字段**：

| 字段 | 说明 |
|------|------|
| `name` / `type` | 渠道名称和分类 |
| `baseScore` | 推荐优先级评分（0-100） |
| `costLevel` | 费用等级：low / medium / high |
| `costDesc` | 费用说明（含建议日预算和月成本估算） |
| `effortLevel` | 精力投入度：low（一键开通） / medium（偶尔维护） / high（持续投入） |
| `threshold` | 开通门槛 |
| `effectDesc` | 效果描述 |
| `searchWeight` | 搜索/流量加权说明 |
| `path` | 简短操作路径（概览用） |
| `detailedSteps` | 分步操作指引（细化到按钮文字） |
| `suitableFor` | 适合谁/什么场景 |
| `notSuitableFor` | 不适合谁/什么情况 |
| `directUrl` | 千牛后台直达链接（可选，有则展示"在千牛打开"按钮） |
| `checkAfter` | 开通后的效果验证方法 |

**推荐逻辑**：
- 读取竞品中各渠道的使用覆盖率
- 已开通的渠道标注"同行 X% 在使用"
- 未开通的高覆盖率渠道排序靠前，标注"推荐开通"
- Hero 推荐：免费 + 一键开通 + baseScore 最高的渠道
- 分组：quickWins（免费高价值）、paid（付费）、later（高门槛/高资质要求）
- 知识库（底部折叠区）展示全部渠道的完整信息，包括适合/不适合判断、分步操作步骤、精力投入度

**截图辅助功能**：
- 无 `directUrl` 的渠道提供粘贴区域
- 用户 Ctrl+V 粘贴千牛截图 → OCR 识别界面文字 → 返回具体操作指引

**输出**：推荐清单 + 诊断汇总，不再单独维护明日清单

### 2.3 活动筛选

**输入**：千牛店铺数据（通过扩展一键扫描或手动拖入 scan-qianniu.json）

**规则引擎**：
- 27 条活动规则（ACTIVITY_RULES），每条含资格条件/费用类型/精力/适用范围/月费/CPC 区间/收益预估/选品建议/分步步骤/直达链接
- 5 维度资格匹配（店铺层级/体验分/近30天订单/保证金/违规次数）
- 四组结果：可参加（全过）、差一步（≤2 项不合格）、暂不可参加、平台暂停

**预算计算器**：
- 月预算上限输入 → 勾选付费活动 → 实时汇总月支出 + 预估曝光/点击 + 超预算警告
- 默认 ¥300，首次使用根据成本价自动推荐起步预算
- 点击活动名跳转到对应卡片（scrollIntoView + 高亮闪烁）

**交互**：
- 筛选开关切换控制卡片显隐
- 「去参加」通过扩展 openWithSteps 打开千牛页面并注入步骤跟随浮动面板
- 千牛推荐数据优先显示（蓝色框），次选收益预估行（绿色框）

### 2.4 店铺诊断

**子模块一：店铺激活向导**
- 8 项清单：店招上传 / 店铺简介 / 类目属性补全 / 店铺认证 / 破零销量 / 首场活动报名 / 微淘基础帖 / 商品短视频
- 进度条实时追踪 → 勾选后该项收起变灰 → 全部完成显示鼓励文案
- localStorage 持久化（`tb_store_checklist`），200ms 防抖
- 「去操作」通过扩展 openWithSteps 打开千牛对应页面

**子模块二：标题工作台**
- 商品选择器 + 舞种/性别/面料/场景输入区 + 价格档位自动显示
- 「抓取竞品关键词」→ 扩展纯关键词搜索 → getKeywordFrequency() 词频分析 → 三级标签（强推绿/防守黄/长尾灰）+ 竞争度判断
- 40s 超时 + 手动输入降级模式 + 缓存 7 天过期提示
- 选中关键词 → 3 策略标题生成（搜索导向/点击导向/均衡导向）→ 30 字硬约束 → 复制/编辑
- 历史记录：按商品名分组，最多 20 条，localStorage 持久化

## 三、数据抓取（浏览器扩展）

### 3.1 扩展架构

`extension/` 目录，Manifest V3：

| 文件 | 职责 |
|------|------|
| `manifest.json` | 权限：`clipboardWrite`、`storage`、`tabs`；注入淘宝 + file:// 页面 |
| `background.js` | Service Worker，编排后台标签页自动流程 |
| `content.js` | 三模式运行：main（消息中继）、search（提取搜索页）、product（提取详情页） |

### 3.2 消息流

```
index.html ──window.postMessage──▶ content.js (main) ──chrome.runtime.sendMessage──▶ background.js
                                                                                         │
                                                                                         ├─ chrome.tabs.create(商品页, active:false)
                                                                                         ├─ chrome.tabs.create(搜索页, active:false)
                                                                                         ▼
                                                                          content.js (taobao) 自动提取 → 回传数据
```

### 3.3 提取字段

**商品详情页**：标题（meta og:title / document.title / DOM）、关键词（词典+N-gram）、店铺、售价、销量、商品ID

**搜索结果页**：商品标题、价格、付款人数、店铺名、天猫标识、活动标签、优惠券、商品ID

### 3.4 已知风险

淘宝使用 CSS Modules 动态类名，选择器依赖 `[class*="doubleCardWrapperAdapt"]` 等属性包含匹配。淘宝改版可能导致选择器全部失效，需在真实淘宝页面做 DOM 诊断后适配。

## 四、页面布局

### 4.1 整体风格

- 主色调：淘宝橙 `#ff5000`
- 布局：左侧设置面板（420px）+ 右侧结果面板（flex: 1）
- Tab 切换（竞品分析 / 推广分析 / 活动筛选 / 店铺诊断），无页面跳转

## 七、技术约束

- 纯前端单页面，无构建工具、无框架依赖
- 浏览器 `file://` 协议运行
- 扩展需在 `chrome://extensions` 开启开发者模式并加载 `extension/` 目录，同时开启「允许访问文件网址」
- JavaScript 不支持 emoji 范围字符类正则（如 `[😀-🙏]`），会导致 `SyntaxError`
- 文件编码 UTF-8
